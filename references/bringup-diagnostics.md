# 首次上电读数诊断（板级 bring-up）

用户自己焊、自己量，然后把几个测点读数丢过来问「为啥」。这里是把读数**反解成根因**的方法，以及四个最常踩的观察陷阱。

## 0. 交付格式（用户口径）

每条结论必须给三样：

1. **判据** —— 依据（手册原文/公式/量纲），不能是「一般来说」；
2. **预期值表** —— 关断态与使能态各一列，让用户拿表对号；
3. **下一步测量清单** —— 2~3 项，每项设计成「二选一定案」（读到 A 就是 X，读到 B 就是 Y），而不是「再查查焊接」。

用户常自带猜测（「是不是电容没焊」「是不是三极管坏了」）——**先评他的猜测对/错并给理由**，再给自己的结论。

## 1. 先分清「真电压」和「虚电压」

- 节点浮空时（MOS 关断、**输出电容未焊**、输入端悬空），DMM 会读出 1~7V，这是漏电/Coss/表笔感应抬起来的。
- 判据：并 10kΩ 泄放 10 秒后应落到 <0.5V；仍高 → 真有通路。
- **输出电容未焊时任何「半开」读数都不可信**（输出端是高阻节点）；先补齐输出电容再判输出行为。

## 2. 使能判据用「栅源电压」，不是栅极对地电压

直通 N-MOS 由控制器驱动时：`Vgs = V_GATE − V_OUT`。

- 控制器类（如 LM5069）正常导通：`GATE ≈ OUT + 12V`。
- 实测 GATE 3V / OUT 6V → Vgs = −3V → **关断**，6V 只是浮空电压。
- 别把「GATE 上有 3V」当成「已经导通」的证据。

## 3. 在电路上量电阻：先算并联路径

分压串里量上端电阻，读数会比标称小很多——**先算并联**：

```
R1 ∥ (R2+R3) = 191k ∥ 14.47k = 13.45k   →  读 14k 是对的，不是装错件
```

规则：**「读数偏低」≠「装错件」**。要么算清楚并联支路，要么单端抬起/离线再量；在没算并联之前不要下「电阻装错」的结论（会给用户白改板）。

## 4. 分压节点读数反解（KCL 三读数法）

对每个分压抽头写电流平衡（流入 = 流出 + 被节点抽走的电流），用读数反解未知量（漏电流、被拉走的电流、实际阻值、实际顶端电压）。

**判据：反解出的模型必须同时复现所有测点**，只对一个不算成立。

实测例（48V 输入、UVLO 2.8V、OVLO 1.7V、PNP 基极 2.2V）：

| 量 | 反解值 |
|---|---|
| I(R1) = (48−2.78)/191k | 237µA |
| I(R2) = 1.7/8.87k | 192µA |
| 进 PNP 发射极 | 45µA |
| I_B = 2.2V/100k | 22µA |
| hFE_eff = I_C/I_B = 23/22 | **≈1**（异常） |

→ 三个读数一次全中，结论是「集电极开路」；换成「电阻装错」或「输入不是 48V」都凑不出第三个数。

**关键陷阱：节点被拉低会同时压低两个抽头**（它们在同一个串联分压里）——所以「UVLO 和 OVLO 都偏低同样的比例」**不能**单独推定「上端电阻变大」；先算清楚节点到底被抽走了多少电流。

## 5. 高边 PNP 使能开关（E 接被拉节点、C 接 GND、B 经 100k 下拉）

| 状态 | 基极 | 被拉节点 |
|---|---|---|
| 正常导通 | ≈0.1~0.3V | ≈0.7~0.9V（B-E 0.6V + 饱和压降） |
| 结通但无集电极通路 | 节点 − 0.6V | 停在分压值，不塌 |

- 基极停在「节点 − 0.6V」而节点不塌 = **B-E 结在导通、但没有集电极电流通路**。
- 算 `hFE_eff = I_C / I_B`：正常 50~200；≈1 → **反向工作（C/E 对调）或集电极开路**。
- **SOT-23 单独那一侧的单脚（pin 3）最易虚焊**：量「焊盘对 GND = 0V」**证明不了管脚接通**（焊盘本来就接地），要从引脚金属部分量，或直接补焊。
- 二极管档分不出 E 和 C（两个结都 0.6V）——判 E/C 只能查规格书的 pin 定义，并与 EDA 封装的焊盘号对照（同系列不同型号的 SOT-23 脚序会不一样，S8550 与 SS8550 就是反的）。

## 6. 台面电源：看 CV/CC，别只看设定值

- 首上电用带限流台面电源（母线电流的 1/10 起），**同时看面板是 CV 还是 CC**。
- CC 态下「电源显示 48V」和「板上母线实际电压」不是一回事：读数整体偏低时先在**板上**（输入座、分压顶端）量，不要在设定值上争。
- 母线电流要问清楚数值；没给电流读数时，所有「输入电压对不对」的结论都只是假设。

## 7. 关断态输出残留电压：并泄放后反解漏电

「并了泄放电阻还掉不到 0V」= 节点上有**恒流源往里灌**，泄放电阻只是把它变成压降。做法：

```
I_leak = V_measured / R_bleed
R_leak ≈ Vin / I_leak          （等效：Vin 经 R_leak 灌进节点）
校验：Vin × R_bleed/(R_leak+R_bleed) 应等于实测值
```

实测：48V 通道关断、输出并 18k 得 0.8V → I=44µA → 等效 **~1MΩ**（48×18/1018=0.85V，吻合）。

按可能性排查（先查不花钱的）：

1. **助焊剂 / 洗板水残留**（手工焊首选）：48V 就在旁边，几十 µA 级漏电非常典型 → 用无水酒精/洗板水刷该芯片-MOS-端子这一片，吹干重测；落到 <100mV 即结案，**不用改设计**；
2. **MOS 的 D-S 漏电**（IDSS 一般 1µA 级，18k 上只有 ~18mV，对不上就是板面问题）；
3. **控制器 OUT/检测脚内部漏电**（µA 级）。

再加一个判别：把 18k 换成 **1k** —— 电压按比例掉（→≈50mV）= 恒流漏；几乎不变 = 电压型源（继续往上查）。

工程结论：关断态几十 µA（2mW 级）**不影响功能**，不值得为它改板；产品化处理＝洗板 ＋ 输出端常装 **100k** 泄放（48V 下 0.5mA/24mW，0805 够），并焊上输出电容（电容漏电远大于该值，残余会降到 mV 级）。

## 8. 状态脚读数验证「芯片到底在不在工作」

判断一颗控制器是否真的在工作，用**状态脚＋参考脚**交叉验，而不是只看输出：

| 量 | 正常关断 | 正常使能 | 无来源的怪值 = 芯片浮空 |
|---|---|---|---|
| UVLO 脚 | <0.7V（被拉低） | ≈3.4V @48V | 停在分压值不塌 |
| PGD / PWR / ALERT | 低（仅当上拉轨带电才会被拉起） | 高 | **3~4V，且上拉轨没电** |
| GATE − OUT | ≈0V | ≈12V | 3V 之类的中值 |

**规则：任何一个「高电平」都要能说出它是被谁拉高的**（上拉电阻接的是哪条轨、那条轨有没有电）。说不出来 → 芯片内部浮空 → 查 GND/VIN 焊点。**同一颗芯片上两个本不该同电位的脚一起停在同一个怪值**（如 PGD 与 PWR 都是 3.6V）＝ 内部参考/地浮了，直接查 GND 与 VIN 的焊点，别先怀疑外围。

## 9. 电压轨输出偏高/偏低：先算设计值，再读 FB，最后挂载复测

DC-DC 输出不对时不要先判芯片坏，按下面三步走，每步都能独立定案：

**① 算设计值**：`Vout = VFB_ref × (1 + Rtop/Rbot)`。VFB_ref 必须来自手册（同一系列不同后缀可能不同；如某 3A SOT-23 buck 是 0.768V），不许用印象值。

**② 让实测值自已解释**：把实测 Vout 与实测 VFB 一起看，反算 `实测比例 = Vout / VFB`，与设计比例对比：

| 现象 | 判定 |
|---|---|
| 实测比例 ≈ 设计比例，VFB 高于基准 | 芯片把 FB 顶高了 → 轻载/Eco-mode 偏置，或芯片基准偏 |
| 实测比例明显小于设计比例 | 分压件的实际阻值不对（读丝印或断电量） |
| VFB ≈ 基准、Vout 却不对 | 采样点/走线没接在输出上（反馈取错点） |

**③ 挂载复测**：D-CAP2 / Eco-mode（跳脉冲）类控制器在**空载**下会靠跳脉冲维持输出，FB 与输出都高于额定（占空比越大偏得越多，5V→3.3V 可比 5V→1.1V 多偏一倍）。对地并 **100Ω（33mA 级）**再测 FB 与 Vout：回落到标称 → 轻载行为，不是故障；仍偏 → 按②的分支处理。D-CAP2 的环路依赖输出电容，输出电容漏焊会不稳/偏高，顺手确认。

**阻值编码**：4 位 E96 编码是「前三位有效数字＋位数」——`3302` = 33.0k、`4301` = **4.30k**（不是 43k）、`1002` = 10.0k。反算时先把编码读对，一个小数点就会让"设计值"算错一倍。

**交叉验证基准**：同一颗芯片驱动的另一路电源（不同输出电压）是免费的基准对照——它按设计比例正确输出，就说明「芯片基准没问题」，问题在被查那一路的比例或负载态。

## 10. 多级电源链的上电门禁

- **一级一测**：母线 → 第一级（如 48V→5V）→ 第二级（5V→3V3 / 1V1）→ 后级负载。每级焊完先空载测电压、再挂 100Ω 测一次，前一级通过才焊下一级；任何一级的输出不对，后面一颗负载芯片都不要焊。
- **绝对最大值门禁**：任何一轨只要超过后级器件的 **absolute maximum**（如某 MCU 的 VDD 上限正好 3.6V），后级芯片就不许焊——「能亮」不等于安全，长期跑在极限上会折寿。修好轨电压再焊。
- 带 **PowerPAD/EP** 的控制器：EP 必须焊到 GND（背面过孔灌锡），没焊会发热、稳压异常；**非同步 buck 的续流二极管漏装则完全没有输出**。
- 每级焊完先洗板再上电（残留助焊剂在高压轨上就是几十 µA 的漏电来源，见 §7）。

## 11. 读数先验真：探针位置与「漂亮数字」

- 读到 0.001V、0.000V 这类「干净得反常」的值，或两个本该相关的测点同时为 0，**先确认探针真的搭在焊盘/引脚上**——表笔悬空时 DMM 就显示 0。高阻节点（输出未挂载、输出电容未焊）尤其容易出这种假读数。
- 拿到一批新读数时，先问/确认「量的是哪个点、黑表笔接哪」，再开始反解；同一节点前后两次读数互相矛盾（0.001V → 1.3V）不是电路变了，多半是测量方式变了。
- 高阻节点改用「并泄放后再量」（§1）能同时解决虚电压和探针接触不良两类假象。

## 12. 高压监测芯片的「母线检测脚」不是高阻：分压器电流会串进滤波电阻

电压/电流监测类芯片的 **VBUS / 母线检测脚内部是分压器**，不是运放输入。手册上「输入偏置电流 2.5nA」这类指标通常只针对**差分采样脚**；母线脚在几十伏下会吃**几十 µA**。

- **症状**：通道空载，采样读数却有一个固定差分电压（例：48V 母线下读到 −0.4mV 量级，按 2mΩ 折算成 −200mA 的「负电流」），而同一批芯片在低母线电压的通道上读数为 0。
- **判据**：`V_offset ≈ V_bus × R_filt / R_div`，**与母线电压成正比、与负载无关**。反解 `R_div = V_bus ÷ (V_offset / R_filt)`，能对上就是它，不用再怀疑芯片坏了。
- **处理**：① 采样点在**滤波电阻之前**取（下一版改，一劳永逸）；② 固件按 `V_bus × k` 做零点补偿（k 由实测反解，随母线电压线性变化）；③ 单纯空载零点标定只能吃掉固定项，吃不掉随电压变化的那部分 —— 别把它当成「传感器精度就这样」。
- **通用规则**：任何「高压侧检测脚 + 串联滤波电阻」的组合，都要按「检测脚会吸电流」来算误差；能在电阻之前取的点，不要放在电阻之后。
