# PCB 叠层、铺铜与地分区（四层板）

定位：画板前定叠层、分区铺铜、判"GND/AGND 怎么分"时读这份。磁珠滤波与反馈取样点的四条判据见 SKILL.md 坑 19；逐路电流应力核对见 `power-rail-audit.md`。

## 1. 四层叠层分配（外层 2oz 起）

| 层 | 放什么 | 不放什么 |
|---|---|---|
| L1 TOP | 器件面；**全部高速**（千兆/百兆差分、RMII 50MHz、屏 SPI、时钟）＋ 局部功率铜皮 | 大电流长距离回流 |
| L2 INNER1 | **参考平面**（角色见 §3），千兆差分必须连续 | 除非确有把握，否则不跟着做 GND/AGND 分割 |
| L3 INNER2 | **电源分割**（各路电压各一块）＋ GND 填充（GND 区多打缝合过孔到 L2） | 高速信号 |
| L4 BOTTOM | 功率铜皮/回流 ＋ **只有慢信号**（I²C/UART/使能/PGD/采样） | 高速——它的参考是带分割的 L3 电源层 |

介质：L1↔L2 约 0.2mm（差分阻抗/紧耦合参考）；L2↔L3、L3↔L4 用较厚芯板（耐压＋机械强度）。

## 2. 大电流与采样

- 母线级（10A 以上）：**外层大面积铜 ＋ 内层平面 ＋ 多过孔并联**（0.3~0.4mm 过孔按 ~1A 估，20 个以上）；单纯加宽线宽在 2oz 也只能到 ~6.6mm/21A，不可行时改层间并联。
- 采样电阻（mΩ 级）必须开尔文：从**外侧焊盘**引一对细线，不从焊盘中心或电流路径内侧引；成对、等长、包地，与功率电流路径垂直交叉。

## 3. 地分区：区域可以分，参考平面不要跟着切

1. 外形分区（L1/L4 铺铜）：功率区铺 GND、控制/小信号区铺 AGND —— 可以。
2. **L1 与 L2 的分界缝必须同位置**：一层分、另一层不分 → 信号换参考时阻抗突变。
3. 缝沿"功率区 ↔ 控制区"的**物理边界**走，**缝下不许跨任何高速**（高速全部留在同一侧）。
4. 跨缝的低速信号（采样 I²C、使能、PGD、DAC 电压）：**不在缝上换层**，并在缝附近给高频回流一条路 —— 单点连接电阻（如 0Ω）旁并一颗 100nF。
5. 缝合过孔：GND 铜 → L2 用约 5mm 阵列；AGND 铜不与 GND 缝合过孔相连，只在单点汇合。

## 4. 别做"整板一刀切 GND/AGND"

功率区内部本身就混着两种地：

- DCDC 控制器常有两个地脚（PGND + AGND），反馈/补偿/频率设定/使能脚都在安静地一侧；
- 高边电流监测芯片坐在功率区，但它的地属**测量/安静域**；
- 只有开关管源极、输入/输出电容、采样电阻、续流回路走功率地。

→ 规则：**每颗 DCDC 的 AGND 与 PGND 各自就近回流**，功率回流绝不允许穿过 IC 的安静地脚（穿过＝采样与环路直接脏）。分区是"每颗芯片脚边的局部收束"，不是全板一条线。

## 5. 独立铜岛（不参与上面的分区）

- **各隔离通道的隔离地**：各成独立铜岛，互不相连，也不接 GND/AGND。
- **PE / 机壳**：单独一块；RJ45 屏蔽脚、安装孔焊盘、电源模块 PE 端子接入；与板地之间按方案用 0Ω 或 0Ω∥Y 电容单点连接（塑料壳方案则明确不装）。

## 6. 交付前自查

- [ ] 高速信号是否都在参考平面连续的那一层？有无跨缝/跨分割？
- [ ] L1/L2 分界缝位置是否一致、是否落在物理边界上？
- [ ] 每条跨缝低速信号附近是否有高频回流路径（100nF）？
- [ ] 每颗 DCDC 的 AGND/PGND 是否各自就近回流？功率回流有没有穿过安静地脚？
- [ ] 隔离地是否真的互不相连？PE 是否与 GND 分开？
- [ ] 大电流路径是否多过孔并联 ＋ 外层大面积铜？
