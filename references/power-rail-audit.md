# 逐路电源的电流/电压承载核对（交付前必做一遍）

用途：进 PCB 前（或评审时）把**每一路电源的整条电流链**逐环核对，结论必须逐条附依据（用户不接受凭记忆的结论，会自己复核挑错）。

## 一、先把口径钉死

- 每路的**额定电流**（可调路取上限）与**最高输出电压**（决定该路电容耐压）。
- 母线电流 = 总功率 ÷ 母线电压；写清"是否允许同时满发"的组合约束。
- 分别说清**硬件兜底限流点**（采样电阻 + 比较器/控制器阈值算出）与**软件限流点**，并保证两者用同一条采样链、同一个阻值标定（口径不一致＝软件刻度差几倍）。

## 二、逐环清单（每一环都拿手册额定比实际应力）

| 环 | 额定看什么 | 实际应力怎么算 |
|---|---|---|
| 输入座 / 输出座 / 端子排 | 额定电流（按**峰值**取）、耐压、线规 | 该路额定 + 余量 |
| 采样电阻（分流器） | 功率额定、TCR、封装、开尔文取点 | I²R（按兜底限流点算最坏） |
| 开关管 | Vds、Id、Rds(on)@实际 Vgs、SOA（热插拔/浪涌） | I²·Rds(on) + 开关损耗；热插拔另查 SOA |
| 电感 | **Irms（热）与 Isat（饱和）是两个额定，别混** | Ipk = Iout + ΔI/2，ΔI = (Vin−Vout)·D/(L·fsw)，D = Vout/Vin |
| 输入电容 | 纹波电流额定（与频率相关）、耐压 ≥2×、陶瓷在直流偏压下容值降 30~60% | 输入纹波 ≈ Iout·√(D(1−D))（多路按不相关求和） |
| 输出电容 | 纹波电流额定、耐压按该路**最高输出**（可调路取上限） | ΔI/√12（buck 输出） |
| 续流/整流二极管 | 反向耐压 ≥ Vin(max)、峰值电流 > 电感峰值 | 见三① |
| 控制器 / 稳压器 | 输出电流额定、输入电压范围（含绝对最大值）、栅极驱动电压 | 该路负载 |
| 限流 / 保护 | 控制器手册给的限流公式与源电流 | 见三③ |

## 三、实测最容易犯的三类错

① **非同步 buck 漏掉外接续流二极管**。控制器内部只有高边管时，手册会写 "requires an external catch diode between SW and GND"（耐压 ≥ Vin(max)、峰值电流 > 电感峰值）。缺它电感电流无处续流 → 该路**完全没有输出**（不是效率低，是不工作）。选型阶段就按"同步 / 非同步"决定外围清单里有没有二极管；审计时**在开关节点网络成员里找二极管**，找不到就是漏了。

② **采样/反馈点与串联滤波元件的位置关系搞错**。串联元件（磁珠 / 0Ω / 互感器）之后的压降不会被反馈补偿；判据 = `I_load × DCR ÷ 轨电压`：**<1% 反馈可留在主轨**（否则会把 LC 极点与 DCR 温漂拉进控制环），**>2~3% 必须把反馈挪到负载侧或把串联件换 0Ω**。

③ **限流点远高于电感承载能力**。Rds(on) 采样型控制器：限流 ≈ `R_ILIM × I_ILIM(手册源电流) ÷ Rds(on)`（注意源电流随温度有 TC）。限流设成电感 Isat 的 3~4 倍＝过流时电感先饱和、芯片还没保护；设太紧则满载/浪涌误动作。

## 四、串磁珠（或 LC 滤波）的四个条件

1. **两侧都有电容**——只有一侧有电容时，电容就被挡在被保护器件之外（典型错法：电容全挂在磁珠远端、IC 电源脚在近端）。
2. **被保护的器件在电容那一侧**。
3. **磁珠额定电流 ≥ 支路电流**（0603 / 600Ω 磁珠通常只有 1A 级、DCR 约 150mΩ），否则压降大、发热、磁芯饱和。
4. **反馈取样点按第三节②的判据处理**。

补充：磁珠是"频率相关的电阻"，不是储能电感——直流只看 DCR；它的作用是把高频噪声挡在一侧，**不等于降低纹波或稳压**。要不要串取决于该域有没有需要隔离的敏感部分；数字内核域常见做法是"电源平面 + 每脚就近电容"，不串磁珠。若确实要串，记得大电流域优先 0Ω。

## 五、结论怎么写（用户要的形式）

- 一张**逐路表**：`# / 电路 / 规定电流 / 链上器件（额定 + 立创编号）/ 实际应力 / 结论`，结论用 ✅够 / ⚠️边缘 / 🔴必须改。
- **必改项单独成"必改清单"**：每条带手册依据（能引原句就引原句）+ 具体改法（加哪颗料、改哪个值、改哪条网络、改哪颗电感）。
- 边缘项写清"多少 A 以内没问题、超过要换什么"，别只报"偏高"。
